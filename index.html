The hypothetical processor

  • 0001 = 1 = Load AC from memory
  • 0010 = 2 = Store AC to memory
  • 0101 = 5 = Add to AC from memory
  • 0011 = 3 = Load AC from I/O
  • 0111 = 7 = Store AC to I/O

The first 4 bits of an instruction are the opcode; the remaining 12 bits are the argument (a memory address or an I/O device number). The program loaded into memory is: 300 [3005]  301 [5940]  302 [7006], with 940 [0002]. Device 5 currently holds 0004.
