### 单元 01 —— 计算机硬件导论
硬件与软件、二进制数、PC 组成部件、主板、存储设备、总线、BIOS/UEFI 以及供电系统。

### 单元 02 —— 第 1 章：计算机系统概述（Stallings）
基本组成元素（处理器、主存、I/O 模块、系统总线）、微处理器的发展、GPU / DSP / SoC、指令执行与指令周期、中断（分类、控制转移、多重中断）、存储器层次结构、局部性原理、辅助存储器、高速缓冲存储器（Cache）与 Cache 设计（块大小、映射函数、替换算法、写策略），一直到章末总结。

### 单元 03 —— 第 2 章：操作系统概述（Stallings）
操作系统是什么、作为资源管理器的作用，操作系统的演进（串行处理 → 简单批处理 → 多道程序设计 → 分时系统），主要成就，进程概念与进程表，内存管理与虚拟内存，调度与进程状态，系统体系结构与多处理器／多核组织，容错，以及 Windows、Linux 与 Android 实例分析。

### 单元 04 —— 第 3 章：进程描述与控制（Stallings）
什么是进程及其两个基本要素、进程控制块中保存的进程要素、轨迹与分派程序、两状态与五状态进程模型、进程的创建与终止、挂起进程与交换、操作系统的控制表、进程控制结构与进程映像、执行模式、进程切换，以及 UNIX SVR4 的进程管理。

### 单元 05 —— 第 4 章：线程（Stallings）
进程与线程（资源拥有的单位 vs 调度的单位）、进程的两个特征、多线程的定义、单线程与多线程方式、多线程环境中进程提供什么、每个线程各自拥有什么与共享什么、线程的好处与在单用户系统中的用途、线程状态及 spawn/block/unblock/finish 操作、线程同步，以及用户级线程（ULT）与内核级线程（KLT）的比较。

## 功能特点

- **一页一幻灯片** —— 五个单元共 254 个独立页面。
- **课件原图** —— 每个页面顶部都有真实幻灯片的整宽扫描图（共 254 张）。纯展示：不可点击，且始终按屏幕宽度自适应缩放。
- **顶部与底部都有 Back / Next** —— 翻页不必再滚到页面底部。
- **自适应导航栏** —— 首页顶部的可折叠导航条。桌面端每一章以下拉菜单展开（幻灯片 + 复习题）；手机端整行收进汉堡按钮，每个分组变成可展开的手风琴，可直接跳转到想复习的章节。
- **中英对照** —— 每一条原文后面紧跟中文翻译。
- **点击朗读** —— 标题和每条英文后面都有小喇叭按钮，用浏览器内置语音朗读（自动跳过中文行）。
- **教材答案高亮** —— 标准答案用暖色高亮块，幻灯片要点做成带编号的低刺激卡片，中文行用柔和薄荷底色。
- **模拟考题** —— 幻灯片页面上有 686 道点击展开的题目（附答案与出处），重点回忆题页另有 25 道，4 道带输入框的简答题，以及 2026 年秋季真题 5 道。
- **复习题整页直显** —— 第 1–4 章复习问答页的所有答案直接显示（无需点击展开），整页内容可一次性浏览与复制。
- **作答自测** —— 一个要点一个输入框，自动判分：要点顺序不限，英文或中文作答都接受，并会提示漏掉的关键词。
- **可搜索导航** —— 可折叠侧边栏支持实时筛选，每个单元页也带关键词过滤框。
- **键盘快捷键** —— `←` 上一页，`→` 下一页，`Esc` 回到首页。
- **进度条** —— 显示当前在本单元中的进度。
- **响应式与动效** —— 滚动渐显、光球背景、水波纹点击效果、页面过渡动画。
- **零依赖** —— 纯 HTML / CSS / 原生 JavaScript，无需构建、无需 npm、不使用框架。

## 练习模块

| 练习 | 位置 | 题数 | 输入框 |
|------|------|:----:|:------:|
| 指令周期填空题 | 首页 `index.html` | 10 | 12 |
| Quiz1importantShortAnswer | `pages/Quiz1importantShortAnswer.html` | 4 | 19 |

两套练习都会自动批改你写的内容：

- **一分一个输入框** —— 框的数量始终等于该题的分值／要点数。
- **顺序不限** —— 任意一个框都可以匹配任意一个尚未使用的要点。
- **判分宽容** —— 不评大小写、空格和完整句子；英文或中文作答都认，改写也算对。
- **简写算对** —— 例如写 `25` 可对应「11001 in binary equals 25 in decimal」，写 `RAM` 可对应「Memory (RAM) size」。
- **列出缺失关键词** —— 让你清楚知道该背哪些词。
- **操作按钮** —— `Check` 判分、`Show answers` 看标准答案、`Clear` / `Reset` 重来，`Ctrl`+`Enter` 快速检查。

## 使用方法

### 方式二 —— 本地服务器（推荐）
```bash
cd CSIS-2260review
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

### 方式三 —— GitHub Pages
把仓库推送到 GitHub，然后进入 **Settings → Pages → Build and deployment → Deploy from a branch**，选择 `main` / `/ (root)`。站点会发布在 `https://<用户名>.github.io/<仓库名>/`。
