Advantages of KLTs

KLT 的优点

Excerpted from “Ch04v2a.pdf” — Page 21
← Back Next →

Original Content (verbatim)

  • The kernel can simultaneously schedule multiple threads from the same process on multiple processors内核可以把同一进程的多个线程同时调度到多个处理器上
  • If one thread in a process is blocked, the kernel can schedule another thread of the same process如果进程中某个线程被阻塞，内核可以调度同一进程中的另一个线程
  • Kernel routines themselves can be multithreaded内核例程本身也可以是多线程的
