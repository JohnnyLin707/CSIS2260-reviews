Disadvantages of ULTs

ULT 的缺点

Excerpted from “Ch04v2a.pdf” — Page 19
← Back Next →

Original Content (verbatim)

  • In a typical OS many system calls are blocking在典型操作系统中，许多系统调用是阻塞的
  • When a ULT executes a system call, not only is that thread blocked, but all of the threads within the process are blocked as well当一个 ULT 执行系统调用时，不仅该线程被阻塞，进程内的所有线程也都被阻塞
  • In a pure ULT strategy, a multithreaded application cannot take advantage of multiprocessing在纯 ULT 策略下，多线程应用无法利用多处理器的优势
  • A kernel assigns one process to only one processor at a time, so only a single thread within a process can execute at a time内核一次只把一个进程分配给一个处理器，因此一个进程中同一时刻只能有一个线程执行
