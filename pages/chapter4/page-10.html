Thread Use in a Single-User System

单用户系统中的线程用途

Original Content (verbatim)

  • Foreground and background work前台与后台工作
  • In a spreadsheet program, one thread displays menus and reads input, another thread executes user commands在电子表格程序中，一个线程负责显示菜单和读取输入，另一个线程执行用户命令
  • Asynchronous processing异步处理
  • For a word processor, a thread can be used to write its RAM buffer to disk对字处理程序来说，可以用一个线程把 RAM 缓冲区写入磁盘
  • Speed of execution执行速度
  • One thread can compute while another reads data from a device一个线程可以在计算的同时，另一个线程从设备读取数据
  • Modular program structure模块化程序结构
