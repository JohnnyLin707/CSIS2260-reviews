Original Content (verbatim)

  • (a) RPC using a single thread(a) 使用单个线程的 RPC
  • (b) RPC using one thread per server, on a uniprocessor(b) 每个服务器一个线程（单处理器上）
  • With a single thread, Process 1 is blocked waiting for the response to the RPC使用单个线程时，进程 1 因等待 RPC 的响应而阻塞
  • With one thread per server, Thread A and Thread B of Process 1 can keep working while one of them waits每个服务器一个线程时，进程 1 的线程 A 与线程 B 可以在其中一个等待时继续工作
  • Blocked waiting for the response to the RPC; blocked waiting for the processor, which is in use by another thread阻塞等待 RPC 响应；阻塞等待处理器（处理器正被另一个线程占用）

With a single thread the whole process blocks while waiting for the response; with one thread per server the other threads of the same process can keep running.

单个线程时整个进程都要等待响应；每个服务器一个线程时，同一进程的其它线程可以继续运行。
