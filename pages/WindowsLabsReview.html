Lab 1 — Windows 10 System Information & Basic Settings

  • System information: Start > All apps > Windows System > right-click This PC > Properties (Windows 11: Settings > System > About).
  • It shows Processor, Installed memory (RAM) and System type (e.g. “64-bit operating system, x64-based processor”).
  • Windows Settings main items: System, Bluetooth & devices, Network & internet, Personalization, Accounts, Time & language, Privacy & security, Update & security, Apps, Gaming, Accessibility.
  • Display: Settings > System > Display → resolution. Storage: Settings > System > Storage → total and used space on C:.
  • Recovery: Settings > Update & Security > Recovery → Reset this PC, Advanced startup.
? Lab 1 · Predicted Questions (6 questions · click to reveal)

From Start > All apps > Windows System, right-click This PC and select Properties (in Windows 11: Settings > System > About). The window shows the Processor, the Installed memory (RAM) and the System type.

Example from the lab: Processor = Intel(R) Core(TM) i5-14500 (2.60 GHz); Installed memory = 16.0 GB; System type = 64-bit operating system, x64-based processor.

Source: Lab1v2.pdf (Part A, Q1) · jinran1.docx

It means the operating system is a 64-bit version and the CPU is an x64-based (64-bit) processor. The two halves match, so the OS can use the full 64-bit instruction set of the CPU.

It matters because a 64-bit OS can address far more than 4 GB of RAM and can run 64-bit applications, whereas a 32-bit OS is limited to about 4 GB of address space.

Source: Lab1v2.pdf (Part A, Q1) · jinran1.docx

Any four of: System, Bluetooth & devices, Network & internet, Personalization, Accounts, Time & language, Privacy & security, Update & security, Apps, Gaming, Accessibility.

For example: (1) System, (2) Bluetooth & devices, (3) Network & internet, (4) Personalization.

Source: Lab1v2.pdf (Part A, Q2) · jinran1.docx

The Recovery page provides “Reset this PC” and “Advanced startup” (newer Windows 10/11 builds also show “Go back to the previous version of Windows” and “Quick machine recovery”).

“Reset this PC” reinstalls Windows (optionally keeping personal files), while “Advanced startup” restarts the computer into the Windows Recovery Environment.

Source: Lab1v2.pdf (Part A, Q4) · jinran1.docx

Open Settings > System > Storage; the page shows how much space is used and how much is left on each drive. The same figures appear in File Explorer under This PC.

Lab example: total storage on C: = 471 GB, used space = 233 GB.

Source: Lab1v2.pdf (Part A, Q3b) · jinran1.docx

Display resolution is the number of pixels shown on the screen, written as width × height (for example 1920 × 1080). You change it under Settings > System > Display > Display resolution.

A higher resolution shows more content and sharper text but makes items smaller; a lower resolution shows less content but larger items. Lab examples: 1920×1080, 1600×900, 1024×768.

Lab 2 — Virtual Machine Import & User Account Management

  • Oracle VirtualBox: open-source virtualization software for x86 and AMD64/Intel64; a Type 2 hypervisor that runs as an application on a host OS.
  • Import: File > Import Appliance → select the .ova file; rename the VM, set the Machine Base Folder, generate new MAC addresses, import hard drive as VDI.
  • Virtual disk: virtual size = maximum capacity (50.00 GB); actual size = space used on the host (11.91 GB).
  • Accounts: Standard User (restricted) vs Administrator (complete control); located at Settings > Accounts > Family & other users or Control Panel > User Accounts.
? Lab 2 · Predicted Questions (8 questions · click to reveal)

Oracle VirtualBox is a general-purpose, open-source virtualization software application for x86 and AMD64/Intel64 architectures; it is used to create virtual machines that can run various operating systems.

It is categorized as a Type 2 hypervisor, which runs as an application on top of an operating system (the host OS), unlike a Type 1 hypervisor that runs directly on the hardware.

Source: Lab2v2.pdf (Introduction) · jinran2.docx

A Type 1 hypervisor runs directly on the bare hardware (bare-metal), so the guest OS runs on the hypervisor with no host OS in between (for example VMware ESXi, Microsoft Hyper-V).

A Type 2 hypervisor runs as an ordinary application on a host operating system (for example Oracle VirtualBox, VMware Workstation), which is why VirtualBox needs Windows installed first.

Source: Lab2v2.pdf (Introduction) · jinran2.docx

An .ova file is an Open Virtualization Appliance: one package that contains the virtual machine’s configuration plus its virtual hard disk(s), so the whole VM can be moved between computers.

In VirtualBox, use File > Import Appliance, select the .ova file, expand Settings to change the VM name and Machine Base Folder, choose “Generate new MAC addresses for all network adapters”, keep “Import hard drive as VDI” checked, then click Finish.

Source: Lab2v2.pdf (Part A, steps 2–5) · jinran2.docx

(1) The virtual machine folder itself, e.g. “Windows 10 VM USB”, which holds the VM configuration, and (2) the virtual disk file, e.g. “Windows 10 VM-disk001.vdi”.

The .vdi file is the virtual hard disk that the VM boots from and stores its files on.

Source: Lab2v2.pdf (Part A, Q after step 7) · jinran2.docx

The virtual size is the maximum capacity that the virtual disk can ever reach (for example 50.00 GB), i.e. the size the guest OS sees as its hard drive.

The actual size is how much space the .vdi file currently occupies on the host machine (for example 11.91 GB). It is smaller because the disk is dynamically allocated and grows only as data is written to it.

Source: Lab2v2.pdf (Part A, Q) · jinran2.docx

A MAC address is the unique 48-bit hardware address of a network adapter, written as six hexadecimal pairs (for example 08:00:27:67:6F:DA). It is used to identify a device on a local network.

Generating new MAC addresses on import prevents duplicate MAC addresses when the same appliance is imported on several computers or run next to the original VM, which would cause network conflicts.

Source: Lab2v2.pdf (Part A, step 5c and Q) · jinran2.docx

(1) Standard User: an account designed for daily computing that carries restricted privileges to protect the system; it cannot change system-wide settings or install most software.

(2) Administrator: an account with complete control over system files, security settings and user configurations, including creating and changing other accounts and installing software.

In the lab the newly created local account was a Standard User, and the other available option was Administrator.

Source: Lab2v2.pdf (Part B, Q5a–b, Q6) · jinran2.docx

Each user profile under C:\Users is protected by NTFS permissions, so a Standard user is denied access to another user’s folders unless the administrator password is supplied.

An Administrator can click Continue and approve the User Account Control (UAC) prompt, which grants the required access. In the lab, access with the Standard account was “No” and with the Administrator account it was “Yes”.

Source: Lab2v2.pdf (Part B, Q5e–g, Q9) · jinran2.docx

Lab 3 — Windows 10 System Performance

  • Paging file: a reserved portion of the hard drive/SSD used as an extension of physical RAM (virtual memory).
  • Resource Monitor (Windows Administrative Tools): real-time CPU, Memory, Disk and Network; Memory tab shows usage, available memory and Hard Faults/sec.
  • Performance Monitor: Data Collector Sets > System Performance / System Diagnostics; reports under Reports > System.
  • winsat formal runs the System Assessment tool; Desktop Rating gives CPUScore, DiskScore and MemoryScore.
  • Task Manager: Apps, Background processes, Performance (network link speed), Startup.
? Lab 3 · Predicted Questions (10 questions · click to reveal)

A paging file (swap file) is a reserved portion of a computer’s hard drive or SSD that acts as an extension of its physical memory (RAM).

Windows moves the least-recently-used pages out of RAM into the paging file, freeing physical memory for active programs. This is the basis of virtual memory: the system can run more or larger programs than the installed RAM alone would allow, at the cost of slower disk access.

Source: Lab3.pdf (Part A, Q2a) · jinran3.docx

Virtual memory is a memory-management technique that gives programs a logical address space larger than the physical RAM actually installed.

The OS keeps the active pages in RAM and the rest on disk (the paging file), swapping pages in and out as needed, so programs do not have to fit entirely in physical memory.

Source: Lab3.pdf (Part A, Q2) · jinran3.docx

The four main resources are (1) CPU, (2) Memory, (3) Disk and (4) Network.

Each has its own tab showing per-process usage, and the Overview tab graphs all four together in real time.

Source: Lab3.pdf (Part A, Q3a) · jinran3.docx

A hard fault is an event in which the operating system must fetch the required data from the storage drive instead of from fast physical memory (RAM).

A high number of hard faults per second means the system is short of RAM and is paging heavily to disk, which slows the computer down. A soft (page) fault, by contrast, is resolved from RAM or the standby list without touching the disk.

Source: Lab3.pdf (Part A, Q3c) · jinran3.docx

Resource Monitor gives a real-time, per-process view of the four resources (CPU, memory, disk and network) and is used for a quick look at what is happening right now.

Performance Monitor collects data over time using Data Collector Sets (System Performance, System Diagnostics) and presents it as counters and reports under Reports > System, so it is used for measurement, logging and diagnosis rather than a quick glance.

Source: Lab3.pdf (Part A, Q3–Q5) · jinran3.docx

It runs the Windows System Assessment Tool (WinSAT), which benchmarks the computer’s CPU, disk, memory and graphics performance. It must be run from an administrator command prompt and takes a few minutes.

The results appear in Performance Monitor under System Diagnostics > Hardware Configuration > Desktop Rating as CPUScore, DiskScore and MemoryScore (plus graphics scores), each on a scale up to 9.9.

Source: Lab3.pdf (Part A, Q5) · jinran3.docx

(1) OS Checks, (2) Disk Checks, (3) Security Center Tests, (4) Hardware Device and Driver Checks, (5) System Service Checks.

The report marks each item as passed or failed, so a failed check immediately points to the subsystem that needs attention.

Source: Lab3.pdf (Part A, Q5a) · jinran3.docx

DHCP (Dynamic Host Configuration Protocol) Client manages network configuration by automatically registering and updating the computer’s IP address, DNS name and other network parameters.

LSM (Local Session Manager) manages local and remote user sessions: sign-ins, desktop creation, fast user switching and Remote Desktop (RDP) connectivity.

SPOOLER (Print Spooler) manages print jobs: it loads print drivers, intercepts print files and queues them to be sent to the printer. All three were running in the lab.

Source: Lab3.pdf (Part A, Q5b) · jinran3.docx

Because a process can create multiple threads, and the thread is the unit that is actually scheduled and dispatched.

Each process therefore contributes one or more threads, so the system-wide thread count is always larger than the process count; in the lab the mean thread count was about 1,000 while the process count was far smaller.

Source: Lab3.pdf (Part A, Q4d note) · jinran3.docx

Apps are foreground programs that have a visible window and are being used by the user.

Background processes are programs and services running without a visible window (for example system services, updaters and hidden helper processes).

The Startup tab lists the programs that are configured to start automatically when the user signs in; disabling entries there shortens boot time and frees memory. The Performance tab also shows the network link speed.

Source: Lab3.pdf (Part A, Q6) · jinran3.docx

Lab 4 — Disk Management & System Restoration

  • Disk Management (right-click This PC > Manage): number of disks, capacity, file system; shrink / create / delete / extend volumes.
  • Disk Defragmenter (Optimize Drives): HDD only, never SSD; Disk Cleanup removes unnecessary files.
  • System Restore: Control Panel > Recovery > Configure System Restore > System Protection > Turn on system protection > Create a restore point.
  • Windows RE: Shift + Restart > Troubleshoot > Advanced options; Startup Settings.
? Lab 4 · Predicted Questions (10 questions · click to reveal)

Disk Management is the Windows tool for viewing and managing the disks and partitions of the computer. It is opened by right-clicking This PC > Manage > Disk Management.

It shows the number of installed hard disks, the capacity of each drive and the file system used on each volume (for example C: = NTFS, 50.00 GB). From there you can shrink, create, delete and extend volumes.

Source: Lab4v1.pdf (Part A, Q3) · jinran4.docx

A partition is a logical division of a physical disk that the OS treats as a separate volume with its own drive letter and file system.

Shrink Volume reduces an existing volume (for example C: by 1,000 MB) and turns the freed space into unallocated space, which can then be formatted as a new simple volume (for example drive D: of 999 MB). Deleting the volume and extending C: returns the space to the original drive.

Source: Lab4v1.pdf (Part A, Q4) · jinran4.docx

NTFS (New Technology File System) is the file system used by modern Windows versions on the C: drive.

It supports very large volumes and files, file- and folder-level permissions, journaling for crash recovery, compression, encryption (EFS) and disk quotas, which is why Windows installs on NTFS rather than on the older FAT file systems.

Source: Lab4v1.pdf (Part A, Q3c) · jinran4.docx

An HDD stores data on rotating platters with a moving read/write head, so fragmented files force extra head movement and slow access; defragmentation rearranges the files into contiguous blocks to speed up reading.

An SSD has no moving parts and accesses any block at the same speed, so defragmentation brings no speed benefit and only wastes the limited write cycles, shortening the drive’s life. Windows therefore runs TRIM/optimization instead of defragmentation on SSDs.

Source: Lab4v1.pdf (Part B, Q1 note) · jinran4.docx

Disk Cleanup reduces the number of unnecessary files on the hard disk to free up disk space and help the computer run faster.

It suggests categories such as Downloaded Program Files, Temporary Internet Files, Thumbnails, Recycle Bin and temporary files; you tick the boxes for the categories you want to delete.

Source: Lab4v1.pdf (Part B, Q2) · jinran4.docx

A restore point is a saved snapshot of the system’s files, settings and registry at a particular moment in time.

System Restore uses it to roll the system back to that earlier state when the computer becomes unstable after an update or a new software installation, without deleting the user’s personal documents. It is therefore advisable to create a restore point before making any major change, and a restore can be undone by running Open System Restore again.

Source: Lab4v1.pdf (Part C) · jinran4.docx

Open Control Panel (Small icons view) > Recovery > Configure System Restore > System Protection tab > select the C: drive > Configure > Turn on system protection > OK.

Then click Create, type a description (for example “Lab 4”) and click Create again; Windows saves the restore point and confirms when it is finished.

Source: Lab4v1.pdf (Part C, steps 1–2) · jinran4.docx

WinRE is a minimal recovery environment that Windows can boot into when the normal system cannot start, giving access to repair and recovery tools.

You can enter it manually by holding Shift while clicking Restart (Shift + Restart) and then choosing Troubleshoot > Advanced options.

Source: Lab4v1.pdf (Part D) · jinran4.docx

(1) Two consecutive failed attempts to start Windows; (2) two consecutive unexpected shutdowns that occur within two minutes of boot completion; (3) a Secure Boot error (except for issues related to Bootmgr.efi); (4) a BitLocker error on touch-only devices.

In all four cases Windows cannot start normally, so it falls back to the recovery menu instead of failing completely.

Source: Lab4v1.pdf (Part D, introduction) · jinran4.docx

The recovery options are (1) Startup Repair, (2) Startup Settings, (3) Command Prompt, (4) Uninstall Updates, (5) System Restore and (6) System Image Recovery.

Startup Settings restarts Windows and lets you change startup behaviour for troubleshooting. Four of its options are: Enable debugging, Enable boot logging, Enable Safe Mode with Networking, and Disable automatic restart after failure (others include Enable Safe Mode, Safe Mode with Command Prompt and Disable driver signature enforcement).

Source: Lab4v1.pdf (Part D, Q3–Q5) · jinran4.docx
? Cross-Lab Comparison Questions (3 questions · click to reveal)

Task Manager is best for a quick overview and for stopping a program: it lists Apps, Background processes and Startup items, and its Performance tab gives simple graphs of CPU, memory, disk, network and link speed.

Resource Monitor is best for finding which process is using which resource right now: it shows per-process CPU, memory, disk and network activity and details such as Hard Faults/sec.

Performance Monitor is best for measurement over time and for diagnosis: it runs Data Collector Sets such as System Performance and System Diagnostics and produces reports (utilization, process/thread counts, services, desktop rating).

Source: Lab3.pdf (Part A, Q3–Q6) · jinran3.docx

System Restore rolls system files, settings and the registry back to a restore point while keeping personal files; it is the lightest option and is reversible.

Reset this PC reinstalls Windows from scratch, optionally keeping personal files but removing installed programs and settings; it is used when the system is badly broken.

System Image Recovery restores the entire system from a previously created system image, returning both the OS and all data and programs to the state captured in the image. It is the most complete, and the slowest, of the three.

Source: Lab1v2.pdf (Recovery) + Lab4v1.pdf (Parts C–D) · jinran1.docx / jinran4.docx

A Standard User runs with restricted privileges, while an Administrator has complete control over the system. To limit the damage a compromised program could do, even an Administrator normally runs with a standard token.

When an action needs administrator rights, UAC shows a consent or credential prompt; only after approval is the elevated token used. This is why a Standard user must supply the administrator password to open another user’s folder, while an Administrator only has to click Continue.

Source: Lab2v2.pdf (Part B) · jinran2.docx
