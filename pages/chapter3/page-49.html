System Interrupts

系统中断

Original Content (verbatim)

  • System interrupt: an event that interrupts the execution of the currently running process and hands control of the processor to the OS系统中断：打断当前进程的执行、把处理器控制权交给操作系统的事件
  • A process switch may occur any time that the OS has gained control只要操作系统取得了控制权，就可能发生进程切换
  • Class 1 — Interrupt: due to some sort of event that is external to and independent of the currently running process第 1 类 —— 中断（Interrupt）：由与当前进程无关的外部事件引起
  • Asynchronous: it is external to the execution of the current instruction异步：产生于当前指令执行之外
  • Clock interrupt时钟中断
  • I/O interruptI/O 中断
  • Memory fault存储器故障
  • Time slice: the maximum amount of time that a process can execute before being interrupted时间片：进程在被中断之前可以执行的最长时间
  • Class 2 — Trap: an error or exception condition generated within the currently running process第 2 类 —— 陷阱（Trap）：当前运行的进程内部产生的错误或异常状况
  • Synchronous: it is associated with the execution of the current instruction同步：与当前指令的执行相关
  • The OS determines if the condition is fatal由操作系统判断该状况是否致命
  • If fatal, the process is moved to the Exit state and a process switch occurs若致命，进程被移入退出态并发生进程切换
  • The action will depend on the nature of the error and the design of the OS具体动作取决于错误的性质和操作系统的设计

How to read the two columns: “system interrupt” is the UMBRELLA term for every event that takes control away from the running process; it splits into two mutually exclusive classes by SOURCE. Interrupt = external + asynchronous (clock, I/O, memory fault; a finished time slice is reported to the OS by the clock interrupt). Trap = internal + synchronous (an error or exception raised by the process itself). They are not two unrelated things — they are the two subclasses of the same mechanism. A third mechanism, the supervisor call, is listed on slide 48.两栏的读法：“system interrupt” 是总称，泛指一切把控制权从运行进程手中取走的事件；按来源分为互斥的两类。Interrupt＝外部、异步（时钟、I/O、存储器故障；时间片用完由时钟中断报告给操作系统）。Trap＝内部、同步（进程自身产生的错误或异常）。二者并非互不相干，而是同一机制的两个子类。第三种机制——管态调用（supervisor call）——列在第 48 页。

Into two classes, Interrupt and Trap, classified by the SOURCE of the event: an interrupt comes from outside the currently running process and is asynchronous, while a trap is generated inside the currently running process and is synchronous. Together they form the single umbrella mechanism called the system interrupt.

分为两类：Interrupt（中断）与Trap（陷阱），依据是事件的来源：中断来自当前进程之外，是异步的；陷阱产生于当前进程内部，是同步的。二者合在一起构成称为“系统中断”的同一个总机制。

当前运行的进程内部产生的错误或异常状况。由于它与当前指令的执行相关，因此是同步的。随后由操作系统判断该状况是否致命。
