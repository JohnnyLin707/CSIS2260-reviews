0.0 Getting Help · 获取帮助

  • On-line manuals give information about most commands: the manual page tells you which options a command can take and how each option modifies its behaviour.在线手册提供了大多数命令的信息：手册页说明某个命令有哪些选项，以及每个选项如何改变命令的行为。
  • man command reads the manual page of a particular command.man command 用于读取某个命令的手册页。
  • man wc shows the manual page of the wc (word count) command.man wc 查看 wc（单词计数）命令的手册页。
  • whatis command gives a one-line description of the command, but omits information about options.whatis command 用一行简要说明该命令，但不含选项等信息。
  • apropos keyword lists the commands whose manual page header contains the keyword.apropos keyword 列出手册标题中含有该关键字的命令。
  • Try typing apropos copy.例如输入 apropos copy。
  • * matches any number of characters; ? matches one character.* 匹配任意多个字符；? 匹配一个字符。

1.1 Listing files and directories · 列出文件与目录

  • When you first log in, your current working directory is your home directory; it has the same name as your user name and holds your personal files and subdirectories.登录时，当前工作目录就是你的主目录；它与你的用户名相同，用来保存你的个人文件和子目录。
  • ls (list) lists the contents of the current working directory.ls（list）列出当前工作目录的内容。
  • If the directory is empty, the UNIX prompt is simply returned.如果目录是空的，UNIX 只会返回提示符。
  • The System Administrator may also have put some files there when your account was created.系统管理员也可能在创建你的账户时放了一些文件进去。
  • ls does not show files whose name begins with a dot (.). These are hidden files and usually contain important program configuration information; they are hidden because you should not change them unless you are very familiar with UNIX.ls 不会显示名字以点（.）开头的文件。这些是隐藏文件，通常保存重要的程序配置信息；之所以隐藏，是因为除非你非常熟悉 UNIX，否则不应修改它们。
  • ls -a lists all files, including the hidden ones.ls -a 列出所有文件，包括隐藏文件。
  • Options change the behaviour of a command; -a is an example of such an option.选项（options）用来改变命令的行为，-a 就是 ls 的一个选项。
  • Exercise 1a: make another directory inside unixstuff called backups.练习 1a：在 unixstuff 目录中再创建一个名为 backups 的目录。

1.2 Making directories · 创建目录

  • mkdir unixstuff (make directory) creates a subdirectory called unixstuff in your current working directory.mkdir（make directory）在当前工作目录下创建一个名为 unixstuff 的子目录。
  • Use it to hold the files you will create during this tutorial.用它来存放你在本教程中要创建的文件。
  • Type ls to see the directory you have just created.输入 ls 查看刚创建的目录。

1.3 Changing to a different directory · 切换目录

  • cd directory (change directory) changes the current working directory to directory.cd directory（change directory）把当前工作目录切换到 directory。
  • The current working directory may be thought of as the directory you are in, that is, your current position in the file-system tree.当前工作目录可以理解为“你所在的目录”，也就是你在文件系统树中的当前位置。
  • cd unixstuff changes to the directory you have just made.cd unixstuff 进入你刚创建的目录。
  • Type ls to see its contents (which should be empty).输入 ls 查看它的内容（此时应该是空的）。

1.4 The directories . and .. · 特殊目录 . 与 ..

  • Every directory contains two special entries: . (dot) and .. (dot dot).每个目录中都包含两个特殊条目：.（点）和 ..（点点）。
  • . means the current directory, so cd . means stay where you are.. 表示当前目录，所以 cd . 表示留在原地（仍在这个目录）。
  • There must be a space between cd and the dot.cd 和点之间必须有一个空格。
  • Using . saves a lot of typing, as we shall see later.使用 . 可以省下大量输入，后文会看到它的用处。
  • .. means the parent of the current directory, so cd .. takes you one directory up the hierarchy... 表示当前目录的父目录，所以 cd .. 会沿层次结构上移一层。
  • Try it now — it takes you back to your home directory.现在试试，它会把你带回主目录。
  • cd with no argument always returns you to your home directory; this is very useful if you get lost in the file system.不带任何参数的 cd 总是回到主目录，在文件系统中迷路时非常有用。

1.5 Pathnames · 路径名

  • Pathnames enable you to work out where you are in relation to the whole file-system.路径名让你知道自己相对于整个文件系统所处的位置。
  • cd first, then type pwd (print working directory) to see the absolute pathname of your home directory.先输入 cd，再输入 pwd（print working directory）查看主目录的绝对路径。
  • The full pathname looks something like /usr/abc, which means abc (your home directory) is in the usr sub-directory, which is inside the top-level root directory called /.完整路径形如 /usr/abc，意思是 abc（你的主目录）在 usr 子目录里，而 usr 在最顶层的根目录 / 之下。
  • Use ls, pwd and cd to explore the file system; if you get lost, type cd by itself.用 ls、pwd 和 cd 探索文件系统；迷路时只要单独输入 cd。

1.6 More about home directories and pathnames · 关于主目录与路径名

  • To use a command on a file that is not in the current working directory, you must either cd to the correct directory or specify its full pathname.要对不在当前工作目录中的文件使用命令，你必须要么 cd 到正确目录，要么给出它的完整路径名。
  • Example: ls backups fails, because backups is not in your current directory.例：ls backups 会失败，因为 backups 不在当前目录里。
  • The error message is backups: No such file or directory.错误信息是 backups: No such file or directory（没有那个文件或目录）。
  • Use the full pathname instead: ls unixstuff/backups.改用完整路径：ls unixstuff/backups。
  • Home directories can also be referred to by the tilde character ~; it can be used to specify paths starting at your home directory.主目录也可以用波浪号 ~ 表示，它可以用来指定从主目录开始的路径。
  • ls ~/unixstuff lists the contents of your unixstuff directory no matter where you currently are.ls ~/unixstuff 无论你当前在哪里，都会列出 unixstuff 目录的内容。
  • Exercise 1b: what do you think ls ~ and ls ~/.. would list?练习 1b：你认为 ls ~ 和 ls ~/.. 会列出什么？

2.1 Copying files · 复制文件

  • cp file1 file2 makes a copy of file1 in the current working directory and calls it file2.cp file1 file2 在当前目录下把 file1 复制一份并命名为 file2。
  • First cd ~/unixstuff.先执行 cd ~/unixstuff。
  • Create a file called sample.txt by typing man cp > sample.txt.输入 man cp > sample.txt 创建一个名为 sample.txt 的文件。
  • Then type cp sample.txt sample1.txt, which makes a copy named sample1.txt.再输入 cp sample.txt sample1.txt，得到一个名为 sample1.txt 的副本。
  • Copying leaves you with two files; moving leaves you with one file.复制之后你会得到两个文件；移动之后只剩一个文件。
  • Exercise 2a: create a backup of sample.txt by copying it to a file called sample.bak.练习 2a：把 sample.txt 复制为 sample.bak，作为备份。

2.2 Moving files · 移动文件

  • mv file1 file2 moves (or renames) file1 to file2.mv file1 file2 把 file1 移动（或重命名）为 file2。
  • Moving has the effect of moving rather than copying, so you end up with only one file rather than two.移动是真正搬走而不是复制，因此结果只有一个文件而不是两个。
  • It can also rename a file: move it to the same directory but give it a different name.它也可以用来重命名：在同一目录内把文件换成另一个名字。
  • Inside unixstuff, type mv sample.bak backups/ to move the file into the backups directory.在 unixstuff 目录内输入 mv sample.bak backups/，把文件移入 backups 目录。
  • Type ls and ls backups to see if it has worked.用 ls 和 ls backups 检查是否成功。

2.3 Removing files and directories · 删除文件与目录

  • rm file (remove) deletes a file.rm（remove）删除文件。
  • Inside unixstuff: cp sample.txt tempfile.txt, ls to check it exists, then rm tempfile.txt, then ls again to check it is gone.在 unixstuff 目录内：先 cp sample.txt tempfile.txt，用 ls 确认已存在，再 rm tempfile.txt，再用 ls 确认已删除。
  • rmdir directory removes a directory; make sure it is empty first.rmdir 删除目录，使用前必须确保目录是空的。
  • You will not be able to remove the backups directory: UNIX will not remove a non-empty directory.你无法删除 backups 目录，因为 UNIX 不会删除非空目录。
  • Exercise 2b: create a directory called tempstuff with mkdir, then remove it with rmdir.练习 2b：用 mkdir 创建 tempstuff 目录，再用 rmdir 删除它。

2.4 Displaying the contents of a file · 显示文件内容

  • clear (clear screen) clears the terminal window, so the output of the following commands is easy to read.clear（clear screen）清空终端窗口，使后面命令的输出更容易看清。
  • It clears all text and leaves the prompt at the top of the window.它清除所有文字，并把提示符留在窗口顶部。
  • cat sample.txt (concatenate) displays the contents of a file on the screen.cat sample.txt（concatenate）把文件内容显示在屏幕上。
  • The file is longer than the window, so it scrolls past and becomes unreadable.文件比窗口长，内容会滚动过去而难以阅读。
  • less sample.txt writes the contents of a file onto the screen a page at a time.less sample.txt 一次显示一页文件内容。
  • Press the space-bar for the next page, type q to quit reading.按空格键看下一页，输入 q 退出阅读。
  • For long files, less is used in preference to cat.对于长文件，应优先使用 less 而不是 cat。
  • head sample.txt writes the first ten lines of a file to the screen.head sample.txt 把文件的前 10 行显示到屏幕上。
  • head -5 sample.txt shows that -5 replaces the default of ten lines by five.head -5 sample.txt 表明 -5 把默认的 10 行改成了 5 行。
  • tail sample.txt writes the last ten lines of a file to the screen.tail sample.txt 把文件的最后 10 行显示到屏幕上。
  • Exercise 2c: how can you view the last 15 lines of the file?练习 2c：如何查看文件最后 15 行？

2.5 Tab completion & command history · 按键补全与命令历史

  • Tab completion saves a lot of time: while typing the name of a file, directory or command, press [Tab] and Ubuntu completes the name for you.Tab 补全非常省时间：输入文件名、目录名或命令名时，按 [Tab] 键，Ubuntu 会帮你自动补全名字。
  • For instance, type tail sa and press [Tab].例如输入 tail sa 然后按 [Tab]。
  • If there is only one unambiguous choice, the filename is completed automatically to sample.txt.如果只有一个明确的候选，文件名会自动补全为 sample.txt。
  • If there are multiple options it will not complete it; press [Tab] once more to see the list of all files that start with what you have typed.如果有多个候选，则不会自动补全；再按一次 [Tab] 会列出所有以已输入字符开头的文件。
  • Here two files start with sa, so it completes as far as it can and shows: sample.txt sample1.txt.这里有两个以 sa 开头的文件，所以它只补到能补的部分并列出：sample.txt sample1.txt。
  • By typing an additional 1 and pressing [Tab] again, the filename is completed.再输入一个 1 并按 [Tab]，文件名即可补全。
  • Command history: press the [Up] arrow and the Terminal shows your previous command; press [Return] to run it again without typing it.命令历史：按 [Up] 方向键可显示上一条命令，按回车即可再次执行，无需重新输入。
  • Press the [Down] arrow to go forward in your command history.按 [Down] 方向键在命令历史中向前翻。

2.6 Searching the contents of a file · 搜索文件内容

  • Inside less sample.txt (do not press q), type a forward slash / followed by the word to search, e.g. /copy.在 less sample.txt 中（不要按 q 退出），输入正斜杠 / 再输入要搜索的单词，例如 /copy。
  • less finds and highlights the keyword; type n to search for the next occurrence.less 会找到并高亮该关键字；输入 n 跳到下一个出现处。
  • grep copy sample.txt searches the file for specified words or patterns and prints each matching line.grep copy sample.txt 在文件中搜索指定的单词或模式，并打印每个匹配行。
  • grep is case sensitive: grep Copy sample.txt does not find copy.grep 区分大小写：grep Copy sample.txt 找不到 copy。
  • Use the -i option to ignore upper/lower case distinctions: grep -i copy sample.txt.用 -i 选项可以忽略大小写：grep -i copy sample.txt。
  • To search for a phrase or pattern, enclose it in single quotes: grep -i 'destination file' sample.txt.要搜索短语或模式，必须用单引号括起来：grep -i 'destination file' sample.txt。
  • Other options of grep:grep 的其他选项：
  • -v display those lines that do NOT match-v 显示不匹配的行
  • -n precede each matching line with the line number-n 在每个匹配行前显示行号
  • -c print only the total count of matched lines-c 只输出匹配行的总数
  • Options can be combined: grep -ivc copy sample.txt counts the lines without the word.选项可以组合使用：grep -ivc copy sample.txt 统计不含该单词的行数。
  • wc (word count) is a handy little utility: wc -w sample.txt counts words, wc -l sample.txt counts lines.wc（word count）是个很实用的小工具：wc -w sample.txt 数单词，wc -l sample.txt 数行数。

3.1 Wildcards · 通配符

  • The character * is called a wildcard, and will match against none or more characters in a file or directory name.字符 * 称为通配符，可以匹配文件名或目录名中任意多个字符（包括零个）。
  • ls list* lists all files starting with list.ls list* 列出所有以 list 开头的文件。
  • ls *list lists all files ending with list.ls *list 列出所有以 list 结尾的文件。
  • The character ? will match exactly one character.字符 ? 恰好匹配一个字符。
  • So ls ?ouse matches files like house and mouse, but not grouse.因此 ls ?ouse 会匹配 house 和 mouse，但不会匹配 grouse。
  • Try ls sample?.txt.试试 ls sample?.txt。

3.2 Filename conventions · 文件命名约定

  • A directory is merely a special type of file, so the rules and conventions for naming files apply also to directories.目录其实只是一种特殊的文件，因此文件命名规则同样适用于目录。
  • In naming files, characters with special meanings such as / * & % should be avoided; also avoid using spaces within names.命名时应避免使用 / * & % 等有特殊含义的字符，也要避免在名称中使用空格。
  • The safest way to name a file is to use only alphanumeric characters, that is letters and numbers, together with _ (underscore) and . (dot).最安全的命名方式就是只用字母和数字，再加上下划线 _ 和点 .。
  • File names conventionally start with a lower-case letter, and may end with a dot followed by a group of letters indicating the contents of the file.文件名通常以小写字母开头，并且可以用点加若干字母结尾来标明文件内容。
  • All files consisting of C code may be named with the ending .c, for example prog1.c.所有 C 代码文件都可以用 .c 结尾，例如 prog1.c。
  • Then ls *.c lists all files containing C code in that directory.在该目录中输入 ls *.c 就能列出所有 C 代码文件。
  • Beware: some applications give the same name to all the output files; some compilers produce a.out unless given the appropriate option.注意：有些程序会给所有输出文件取同一个名字；有些编译器除非给出相应选项，否则都生成 a.out。
  • If you forget that option, rename the compiled file at once, otherwise the next one will overwrite it and it is lost.如果忘了这个选项，应立即给编译出来的文件改名，否则下一个会覆盖它，文件就丢失了。

4.1 Redirection · 重定向

  • Most processes started by UNIX commands write to the standard output (the terminal screen), and many take their input from the standard input (the keyboard).UNIX 命令启动的大多数进程写到标准输出（终端屏幕），很多进程从标准输入（键盘）读取数据。
  • There is also the standard error, where processes write their error messages, by default to the terminal screen.还有标准错误，进程把错误信息写到那里，默认也是终端屏幕。
  • Type cat and press [Return] without naming a file, then type a few words and press [Return].输入 cat 并回车（不指定文件），然后输入几个词并回车。
  • Hold [Ctrl] down and press [d] (written ^D) to end the input.按住 Ctrl 再按 d（写作 ^D）来结束输入。
  • The cat command read the standard input (the keyboard) and copied it to the standard output (the screen).cat 命令从标准输入（键盘）读取，并复制到标准输出（屏幕）。
  • In UNIX, we can redirect both the input and the output of commands.在 UNIX 中，我们可以重定向命令的输入和输出。

4.2 Redirecting the output · 重定向输出

  • We use the > symbol to redirect the output of a command.使用 > 符号来重定向命令的输出。
  • To create a file called list1 containing a list of fruit, type cat > list1.要创建一个包含水果列表的文件 list1，输入 cat > list1。
  • Then type in the names of some fruit, pressing [Return] after each one: pear, banana, apple, then ^D to stop.然后输入水果名，每个之后按回车：pear、banana、apple，最后按 ^D 结束。
  • The cat command reads the standard input and > redirects the output, which normally goes to the screen, into a file called list1.cat 命令读取标准输入，而 > 把通常输出到屏幕的内容重定向到名为 list1 的文件。
  • Type cat list1 to read the contents of the file.输入 cat list1 读取文件内容。
  • Exercise 4a: create another file called list2 containing orange, plum, mango and grapefruit, then read it.练习 4a：再建一个 list2 文件，写入 orange、plum、mango、grapefruit，然后读取它。
  • The form >> appends standard output to a file, so you can add more items to list1.>> 的形式表示把标准输出追加到文件，因此可以继续向 list1 添加内容。
  • Type cat >> list1, add more names (peach, grape, orange), then ^D.输入 cat >> list1，继续添加名字（peach、grape、orange），然后按 ^D。
  • One file now contains six fruit, the other four. cat list1 list2 > biglist joins (concatenates) list1 and list2 into a new file biglist.现在一个文件有六个水果，另一个有四个。cat list1 list2 > biglist 把 list1 与 list2 合并（连接）成新文件 biglist。

4.3 Redirecting the input · 重定向输入

  • We use the < symbol to redirect the input of a command.使用 < 符号来重定向命令的输入。
  • sort sorts a list alphabetically or numerically.sort 对一个列表按字母或数字排序。
  • Type sort, then enter some vegetables (carrot, beetroot, artichoke) and press ^D; the output is sorted.输入 sort，然后输入一些蔬菜（carrot、beetroot、artichoke）并按 ^D，输出就是排序后的结果。
  • With < you can redirect the input to come from a file rather than the keyboard: sort < biglist.使用 < 可以让输入来自文件而不是键盘：sort < biglist。
  • To output the sorted list to a file: sort < biglist > slist, then use cat to read slist.要把排序结果输出到文件：sort < biglist > slist，然后用 cat 读取 slist。

4.4 Pipes · 管道

  • To see who is on the system with you, type who.要查看当前有哪些用户在系统上，输入 who。
  • A way to get a sorted list of names: who > names.txt then sort < names.txt.得到排序的用户名列表可以这样做：who > names.txt 然后 sort < names.txt。
  • That is a bit slow and you have to remember to remove the temporary file when you have finished.这样比较慢，而且结束后还要记得删除临时文件。
  • What you really want is to connect the output of one command directly to the input of the next command; this is exactly what pipes do. The symbol is the vertical bar |.你真正想要的是把一个命令的输出直接接到下一个命令的输入上，这正是管道（pipe）的作用，符号是竖线 |。
  • who | sort gives the same result, but quicker and cleaner.who | sort 得到相同结果，但更快也更干净。
  • To find out how many users are logged on, type who | wc -l.要统计有多少用户已登录，输入 who | wc -l。
  • Exercise 4b: using pipes, display all lines of list1 and list2 containing the letter p, and sort the result.练习 4b：用管道显示 list1 和 list2 中所有含字母 p 的行，并对结果排序。

  • command < file — redirect standard input from a file从文件重定向标准输入
  • command1 | command2 — pipe the output of command1 to the input of command2把命令 1 的输出通过管道接到命令 2 的输入
  • cat file1 file2 > file0 — concatenate file1 and file2 to file0把 file1 与 file2 合并到 file0
  • sort — sort data对数据排序
  • who — list users currently logged in列出当前登录的用户
  • a2ps -Pprinter textfile — print a text file to the named printer把文本文件打印到指定打印机
  • lpr -Pprinter psfile — print a postscript file to the named printer把 postscript 文件打印到指定打印机

5.1 File system security (access rights) · 文件系统安全（访问权限）

  • Type ls -l (l for long listing) to see lots of details about the contents of your directory.输入 ls -l（l 表示长格式列出）可看到目录内容的许多细节。
  • Each file (and directory) has associated access rights; ls -lg also shows which group owns the file.每个文件（和目录）都有相关的访问权限；ls -lg 还会显示文件属于哪个组。
  • Example: -rwxrw-r-- 1 ee51ab beng95 2450 Sept29 11:52 file1示例：-rwxrw-r-- 1 ee51ab beng95 2450 Sept29 11:52 file1
  • In the left-hand column is a 10 symbol string made of d, r, w, x, - and occasionally s or S.最左边一列是由 d、r、w、x、-（偶尔还有 s 或 S）组成的 10 个符号的字符串。
  • If d is present it is at the left end and indicates a directory; otherwise the first symbol is -.如果最左端是 d，表示这是一个目录；否则第一个符号是 -。
  • The 9 remaining symbols are the permissions, taken as three groups of 3.剩下 9 个符号表示权限，分成三组，每组 3 个。
  • The left group gives the permissions for the user that owns the file.左组给出文件所有者（用户）的权限。
  • The middle group gives the permissions for the group of people to whom the file belongs.中组给出文件所属组的权限。
  • The rightmost group gives the permissions for all others.最右一组给出其他所有人的权限。
  • Access rights on files: r read (and copy) the file; w change the file; x execute the file where appropriate.文件上的权限：r 表示读取（复制）文件；w 表示修改文件；x 表示（在适用时）执行文件。
  • Access rights on directories: r allows users to list the files in the directory; w allows users to delete files from it or move files into it; x is the right to access the files in it.目录上的权限：r 允许列出目录中的文件；w 允许从目录中删除文件或把文件移入；x 表示可以访问目录中的文件。
  • To read a file you must have execute permission on the directory containing it, and hence on every directory above it in the tree.要读取某个文件，你必须对它所在的目录以及该目录之上的所有目录都有执行（x）权限。
  • Examples:一些例子：
  • -rwxrwxrwx a file that everyone can read, write and execute.-rwxrwxrwx 人人都可读、可写、可执行的文件。
  • -rw------- a file that only the owner can read and write; no-one else can read or write and no-one has execution rights (e.g. your mailbox file).-rw------- 只有所有者可读写的文件，其他人都不能读写，也没有执行权限（例如你的邮箱文件）。

5.2 Changing access rights · 修改访问权限（chmod）

  • Only the owner of a file can use chmod (change a file mode) to change the permissions of a file.只有文件的所有者才能用 chmod（change a file mode）修改文件权限。
  • Symbols used by chmod:chmod 使用的符号：
  • u user — 用户u 用户
  • g group — 组g 组
  • o other — 其他人o 其他人
  • a all — 全部a 全部
  • r read — 读r 读
  • w write (and delete) — 写（以及删除）w 写（以及删除）
  • x execute (and access directory) — 执行（以及访问目录）x 执行（以及访问目录）
  • + add permission — 增加权限+ 增加权限
  • - take away permission — 去掉权限- 去掉权限
  • To remove read, write and execute permission on biglist for the group and others, type chmod go-rwx biglist; other permissions are unaffected.要去掉 biglist 对组和其他人的读、写、执行权限，输入 chmod go-rwx biglist，其它权限不受影响。
  • To give read and write permission on biglist to all, type chmod a+rw biglist.要给所有人 biglist 的读、写权限，输入 chmod a+rw biglist。
  • Exercise 5a: try changing the permissions of sample.txt and of the backups directory, then check with ls -l.练习 5a：试着修改 sample.txt 和 backups 目录的权限，并用 ls -l 检查结果。

5.3 Processes and jobs · 进程与作业

  • A process is an executing program identified by a unique PID (process identifier).进程是一个正在执行的程序，用唯一的 PID（进程标识号）标识。
  • Type ps to see information about your processes with their PID and status.输入 ps 可以看到你的进程信息及其 PID 和状态。
  • A process may be in the foreground, in the background, or be suspended.进程可能处于前台、后台，或被挂起。
  • In general the shell does not return the UNIX prompt until the current process has finished executing.一般来说，当前进程执行完之前 shell 不会返回 UNIX 提示符。
  • Some processes take a long time and hold up the terminal; backgrounding them returns the prompt immediately and lets you carry out other tasks.有些进程运行很久会占住终端；把它们放到后台可立即返回提示符，让你做其它事情。
  • To background a process, type & at the end of the command line.要把进程放到后台，只需在命令行末尾加上 &。
  • sleep 10 waits ten seconds before returning the prompt; during that time you can do nothing except wait.sleep 10 会等待 10 秒才返回提示符；这段时间里你除了等什么也做不了。
  • sleep 10 & runs the job in the background and returns the prompt straight away.sleep 10 & 在后台运行该作业并立即返回提示符。
  • The machine answers with the job number and the PID in square brackets, e.g. [1] 6259, and notifies you when the background process has finished.机器会用方括号给出作业号和 PID，例如 [1] 6259，并在后台进程结束时通知你。
  • You can suspend a foreground process by holding [Ctrl] and typing [z] (written ^Z), and then put it in the background with bg.按住 Ctrl 再按 z（写作 ^Z）可挂起前台进程，然后用 bg 把它放到后台。
  • Note: do not background programs that require user interaction.注意：不要把需要用户交互的程序放到后台。

5.4 Listing suspended and background processes · 列出挂起与后台进程

  • When a process is running, backgrounded or suspended, it is entered onto a list together with a job number.进程在运行、放到后台或被挂起时，都会连同一个作业号进入一个列表。
  • Type jobs to examine this list, for example [1] Suspended sleep 100.输入 jobs 查看该列表，例如 [1] Suspended sleep 100。
  • To restart a suspended process in the foreground, type fg %jobnumber, for example fg %1.要把挂起的进程恢复到前台运行，输入 fg %作业号，例如 fg %1。
  • Typing fg with no job number foregrounds the last suspended process.不带作业号输入 fg 会把最近挂起的进程调到前台。

5.5 Killing a process · 终止进程

  • It is sometimes necessary to kill a process, for example when a program is in an infinite loop.有时必须终止一个进程，例如程序陷入死循环时。
  • To kill a job running in the foreground, type ^C (hold [control] and press [c]).要终止前台作业，输入 ^C（按住 Ctrl 再按 c）。
  • To kill a suspended or background process, type kill %jobnumber, for example kill %4.要终止挂起或后台进程，输入 kill %作业号，例如 kill %4。
  • Examine the job list again with jobs to check whether the process has been removed.再用 jobs 查看作业列表，确认进程是否已被删除。
  • ps (process status) lists processes with their process numbers (PIDs).ps（process status）列出进程及其进程号（PID）。
  • You can also kill a process by its PID: kill 20077.也可以按进程号终止进程：kill 20077。
  • If a process refuses to be killed, use the -9 option: kill -9 20077.如果进程拒绝终止，使用 -9 选项：kill -9 20077。
  • Note: it is not possible to kill off other users’ processes.注意：你无法终止其他用户的进程。

Summary 4 · 小结（权限与进程）

  • ls -lag — list access rights for all files列出所有文件的访问权限
  • chmod [options] file — change access rights for the named file修改指定文件的访问权限
  • command & — run command in background在后台运行命令
  • ^C — kill the job running in the foreground终止前台作业
  • ^Z — suspend the job running in the foreground挂起前台作业
  • bg — background the suspended job把挂起的作业放到后台
  • jobs — list current jobs列出当前作业
  • fg %1 — foreground job number 1把 1 号作业调到前台
  • kill %1 — kill job number 1终止 1 号作业
  • ps — list current processes列出当前进程
  • kill 26152 — kill process number 26152终止进程号为 26152 的进程

6.1 Other useful UNIX commands · 其他常用命令

  • df reports on the space left on the file system.df 报告文件系统的剩余空间。
  • Use it to find out how much space is left on the fileserver.用它查看文件服务器上还剩多少空间。
  • du outputs the number of kilobytes used by each subdirectory.du 输出每个子目录使用的 KB 数量。
  • Useful if you have gone over quota and you want to find out which directory has the most files.如果你超出配额，可以用它找出哪个目录文件最多。
  • compress file reduces the size of a file, thus freeing valuable disk space, and produces file.Z.compress file 压缩文件以节省磁盘空间，生成 file.Z。
  • Compare with ls -l before and after compressing.可以用 ls -l 比较压缩前后的文件大小。
  • uncompress file.Z restores the original file.uncompress file.Z 还原原始文件。
  • gzip file also compresses a file and is more efficient than compress; it produces file.gz.gzip file 同样压缩文件，而且比 compress 更高效，生成 file.gz。
  • gunzip file.gz unzips the file.gunzip file.gz 解压文件。
  • file * classifies the named files according to the type of data they contain, for example ascii (text), pictures, compressed data.file * 按文件所含数据类型分类，例如 ascii（文本）、图片、压缩数据等。
  • history shows the ordered list of all the commands you have entered.history 显示你输入过的所有命令的有序列表。
  • If you use the C shell, the exclamation character ! recalls commands easily.如果使用 C shell，可以用感叹号 ! 轻松调用之前的命令。
  • !! recall last command — 调用上一条命令!! 调用最近一条命令
  • !-3 recall third most recent command — 调用倒数第三条命令!-3 调用倒数第三条命令
  • !5 recall 5th command in list — 调用列表中第 5 条命令!5 调用列表中第 5 条命令
  • !grep recall last command starting with grep — 调用最近一条以 grep 开头的命令!grep 调用最近一条以 grep 开头的命令
  • Increase the size of the history buffer with set history=100.用 set history=100 可以增大历史记录缓冲区的大小。
