A process has two characteristics: resource ownership and scheduling/execution.

进程具有两个特征：资源所有权与调度/执行。

The process is the unit of resource ownership (it is also called a task): it includes a virtual address space that holds the process image.

进程是资源所有权的单位（也称为任务）：它包含一个容纳进程映像的虚拟地址空间。

The thread is the unit of dispatching: it is also called a lightweight process.

线程是分派的单位：也称为轻量级进程。

Each thread has its own program counter, an execution state (Running, Ready, etc.), a saved thread context when not running, an execution stack and some per-thread static storage for local variables.

每个线程各有自己的程序计数器、执行状态（运行、就绪等）、未运行时保存的线程上下文、执行栈以及用于局部变量的部分线程私有静态存储。

All threads of a process share the memory and resources of that process, and access to them is shared with all other threads in the process.

一个进程的所有线程共享该进程的内存与资源，并与其他线程共享对这些资源的访问。

Multithreading is the ability of an OS to support multiple, concurrent paths of execution within a single process.

多线程：操作系统在一个进程内支持多条并发执行路径的能力。

Source: “Ch04v2a.pdf” — original slides: p.2, p.3（点击链接可跳转查看原教材）

Yes. In a multithreaded environment the process is still the unit of resource allocation and the unit of protection.

仍然需要。在多线程环境中，进程仍然是资源分配的单位和保护的单位。

Associated with the process: a virtual address space that holds the process image.

与进程相关联的是：容纳进程映像的虚拟地址空间。

Protected access to processors, to other processes (for interprocess communication), to files and to I/O resources (devices and channels).

还包括受保护的对处理器、对其他进程（用于进程间通信）、对文件以及对 I/O 资源（设备与通道）的访问。

Suspending a process involves suspending all threads of the process, and termination of a process terminates all threads within the process.

挂起一个进程意味着挂起它的所有线程；终止一个进程也会终止它内部的所有线程。

Source: “Ch04v2a.pdf” — original slides: p.6（点击链接可跳转查看原教材）

1. Foreground and background work: in a spreadsheet program one thread displays menus and reads input while another thread executes user commands.

1. 前台与后台工作：在电子表格程序中，一个线程显示菜单并读取输入，另一个线程执行用户命令。

2. Asynchronous processing: in a word processor a thread can be used to write the RAM buffer to disk from time to time, so the user does not have to wait.

2. 异步处理：在字处理程序中，可以用一个线程定期把 RAM 缓冲区写入磁盘，用户不必等待。

3. Speed of execution: one thread can compute a batch of data while another thread reads the next batch from a device.

3. 加快执行速度：一个线程在计算一批数据的同时，另一个线程从设备读取下一批数据。

4. Modular program structure: a program with many activities is easier to write as one process with several threads than as many separate processes.

4. 模块化程序结构：包含多种活动的程序，写成一个进程多个线程比写成多个独立进程更容易。

Why threads win: it takes less time to create a new thread than a process, less time to terminate it, and less time to switch between two threads than between two processes.

线程更优的原因：创建新线程比创建进程快，终止线程比终止进程快，两个线程之间切换也比两个进程之间切换快。

Threads also enhance communication: all threads of a process share the same address space and the same data, so when one thread alters an item of data in memory the other threads see the results immediately.

线程还使通信更高效：一个进程的所有线程共享同一地址空间和同一份数据，一个线程修改了内存中的数据，其他线程立刻就能看到结果。

Source: “Ch04v2a.pdf” — original slides: p.9, p.10, p.13（点击链接可跳转查看原教材）

Process control block (PCB): in the multithreaded process model there is only one PCB, and it is shared by all threads of the process.

进程控制块（PCB）：在多线程进程模型中只有一个 PCB，由该进程的所有线程共享。

Two examples: the process identifier and the virtual address space (the user address space) of the process.

两项例子：进程的标识符与进程的虚拟地址空间（用户地址空间）。

Others: memory management pointers (segment and page tables), the resources the process owns such as opened files, process privileges, and the parent-child relationships.

其他还有：存储器管理指针（段表与页表）、进程拥有的资源（如已打开的文件）、进程特权以及父子关系。

Thread control block (TCB): each thread has its own TCB, together with its own user stack and kernel stack.

线程控制块（TCB）：每个线程各有自己的 TCB，以及自己的用户栈和内核栈。

Two examples: the execution state of the thread (Running, Ready, Blocked) and its program counter.

两项例子：线程的执行状态（运行、就绪、阻塞）与它的程序计数器。

Others: the saved thread context (register contents) when the thread is not running, the execution stack and the per-thread static storage for local variables.

其他还有：线程未运行时保存的线程上下文（寄存器内容）、执行栈以及用于局部变量的线程私有静态存储。

Source: “Ch04v2a.pdf” — original slides: p.8（点击链接可跳转查看原教材）

Yes. Even on a single processor, threads of different processes are interleaved, so the processor stays busy.

有意义。即使在单个处理器上，不同进程的线程也可以交错执行，处理器因此保持忙碌。

With a remote procedure call (RPC) that uses one thread per server, Thread A and Thread B of a process can keep working while one of them is blocked waiting for the response.

在远程过程调用（RPC）中，如果每个服务器用一个线程，那么进程中线程 A 与线程 B 可以在其中一个等待响应的同时继续工作。

With a single thread the whole process would be blocked while it waits, so the program would stop responding.

若只有一个线程，等待期间整个进程都会被阻塞，程序就会停止响应。

Threads also cost less: creating, terminating and switching threads is faster than doing the same with processes, and they give a cleaner modular program structure.

线程的开销也更小：创建、终止和切换线程都比进程更快，而且程序结构更加模块化。

Source: “Ch04v2a.pdf” — original slides: p.14（点击链接可跳转查看原教材）

The key states for a thread are: Running, Ready and Blocked.

线程的关键状态是：运行态、就绪态和阻塞态。

Spawn: a new thread is created (usually by another thread) and becomes Ready.

派生（Spawn）：创建一个新线程（通常由另一个线程创建），它进入就绪态。

Block: the thread waits for an event, for example an I/O request or a response to an RPC, and moves to Blocked.

阻塞（Block）：线程等待某个事件（例如 I/O 请求或 RPC 响应），进入阻塞态。

Unblock: the event occurs and the thread moves back to Ready.

解除阻塞（Unblock）：事件发生，线程回到就绪态。

Finish: the thread has completed; its register context and stacks are deallocated.

结束（Finish）：线程执行完毕，其寄存器上下文与栈被释放。

There is no thread suspend state: suspending is done to a process and involves suspending all of its threads.

线程没有挂起状态：挂起是针对进程的操作，并且会挂起它的所有线程。

Source: “Ch04v2a.pdf” — original slides: p.12（点击链接可跳转查看原教材）

No. Suspending is a process-level operation: suspending a process involves suspending all threads of the process.

不可以。挂起是进程级的操作：挂起一个进程意味着挂起该进程的所有线程。

All threads of a process share the same address space and the same resources, so a single thread cannot be swapped out of main memory by itself.

一个进程的所有线程共享同一地址空间和同一组资源，因此单个线程无法被单独换出主存。

A thread is only a unit of dispatching inside its process; the process owns the resources that suspension moves to disk.

线程只是进程内部的分派单位；被挂起时换出到磁盘的资源属于进程所有。

In the same way, termination of a process terminates all threads within the process.

同理，终止一个进程也会终止它内部的全部线程。
